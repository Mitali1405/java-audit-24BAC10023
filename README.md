# Student Academic Management System Using OOP

## 1. Project Title

Student Academic Management System Using Object-Oriented Programming

## 2. Overview of the Project

This project is a Java-based Student Academic Management System developed to demonstrate the major concepts of Object-Oriented Programming (OOP).

The project represents students and graduate students using classes, inheritance, abstraction, encapsulation, interfaces, and runtime polymorphism.

The system contains a common abstract Person class. The Student class extends Person, while the GraduateStudent class extends Student.

The SystemOperations interface defines common operations such as displaying records and calculating tuition fees.

## 3. Features

The project provides the following features:

- Create Student and GraduateStudent objects.
- Store person ID, name, email, and GPA.
- Store research grant information for graduate students.
- Validate student name.
- Validate email format.
- Validate GPA between 0.0 and 4.0.
- Validate research grant values.
- Display student records.
- Calculate tuition fees.
- Apply research grant deductions for graduate students.
- Demonstrate inheritance.
- Demonstrate encapsulation.
- Demonstrate abstraction.
- Demonstrate interfaces.
- Demonstrate method overriding.
- Demonstrate runtime polymorphism.
- Demonstrate the use of super and this keywords.
